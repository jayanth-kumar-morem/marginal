## 2. TAM / SAM / SOM method (draft) for the confidential information exchange

**Every line below is an analyst estimate built from the sourced inputs above. The arithmetic is shown. Treat it as directional only. Segments overlap and are measured with different methods.**

### TAM: annual spend on information goods sold between organizations where confidentiality or "inspect before buying" matters

| Segment | Input | Value used |
|---|---|---|
| Financial market data | A1 | $49.2B |
| Alternative data (investment managers) | A2 | $2.8B |
| Expert networks (global) | A4 | ~$3.0B |
| Market-research services (excl. software and reporting) | A6 | $56B |
| AI human/expert data (Mercor gross run rate + Surge 2024 + Scale 2025) | B6–B8 | ~$2B + ~$1B + ~$1B ≈ $4B |
| AI dataset/content licensing | B9 (Grand View dataset market) | ~$3.2B |
| Bug bounties (HackerOne only) | C5 | ~$0.08B |
| **TAM (sum)** | | **≈ $118B/yr** (49.2 + 2.8 + 3.0 + 56 + 4 + 3.2 + 0.08 = 118.3) |

Left out on purpose:
- Data brokers ($290B). Mostly commodity personal data, and the definition is poor.
- IP licensing. No credible number.
- Trade-secret theft ($180–540B). This is a cost of the problem, not spend. Use it only as a "problem severity" line.
- VDR / clean rooms. These are tooling, not goods.

Overlap risk: B6–B9 probably double-count each other.

### SAM: segments where a TEE-appraised, escrowed, on-chain-settled trade fixes a real inspection or leakage problem and the buyers are digital-native

| Segment | Value | Rationale |
|---|---|---|
| Alternative data | $2.8B | Buyers trial datasets before buying, so the inspection paradox is acute |
| Expert networks | ~$3.0B | Knowledge sold per call; compliance (MNPI) risk |
| AI expert/human data | ~$4B | Labs buy proprietary expert knowledge and eval data (Mercor alone >$2B gross run rate) |
| AI content/dataset licensing | ~$3.2B | Value is hard to judge before access |
| Bug bounty + exploit disclosure | ~$0.1–0.2B (HackerOne $81M + Immunefi; grey market not found) | Classic "can't show it without giving it away" |
| **SAM** | **≈ $13B/yr** (2.8 + 3.0 + 4 + 3.2 + ~0.15 = 13.15) | |

Eval sets, model weights and fine-tunes as traded goods: no market figure was **found**. They are an upside option and are not counted.

### SOM: year-5 obtainable revenue (assumptions only, not sourced)

- Assume the exchange captures 1–3% of SAM gross merchandise value (GMV) by year 5: 0.01–0.03 × $13.15B ≈ **$130M–$395M GMV**.
- Assume a 5–15% take rate. Benchmarks: Mercor keeps about 30–40% (experts get 60–70%, B8), and NEAR Intents fees/volume are about 0.15% (F1: $53.4M annualized fees vs about $34.9B cumulative volume, so this is only a rough ratio).
- **SOM revenue ≈ $7M–$59M/yr** (130M × 5% = 6.5M; 395M × 15% = 59.3M).
- Sensitivity: the AI expert-data segment alone grew about 2x in 4 months at Mercor (B8). If that segment reaches $10B+ by 2028, SAM roughly doubles.

### Adjacent candidates, rough anchors

- **AI agent liability/bonding:** Deloitte projects about $4.7B premiums by 2032 (E1). Premiums today are small and not disclosed (Munich Re, Armilla).
- **Verifiable inference:** sits on $12.5B of model-API spend in 2025 (D1), $23.3B of inference IaaS in 2026F (D4), and an Anthropic + OpenAI run rate above $105B (D2–D3). Revenue from verifiable/TEE inference markets is not disclosed anywhere (D11, F2).
- **Agentic payments:** forecasts are large ($1T US by 2030, McKinsey). Measured volume is tiny: x402 is about 138M transactions with 87% under $0.10 (D9), and no card-network volumes are disclosed (D10).
